# Murf-AI-Voice-Agent-Day-2
𝐃𝐚𝐲 𝟐 -  𝐂𝐨𝐟𝐟𝐞𝐞 𝐒𝐡𝐨𝐩 𝐁𝐚𝐫𝐢𝐬𝐭𝐚 𝐀𝐠𝐞𝐧𝐭

I transformed the starter voice agent into a friendly coffee shop barista, trained under the fictional brand Falcon Coffee. The agent now:
✅ Greets customers warmly like a real barista
 ✅ Takes voice-based coffee orders
 ✅ Asks clarifying questions until the order is complete
 ✅ Maintains a structured order state:

{
 "drinkType": "",
 "size": "",
 "milk": "",
 "extras": [],
 "name": ""
}
✅ Automatically saves the final order into a JSON file for processing/analytics
Seeing the agent guide the conversation, confirm preferences, and generate a clean order summary felt like building a tiny Starbucks AI — and I loved it! ☕✨
Next up: pushing this further into a smarter, faster, more human-like ordering experience.
